# inhHAB

Локальный веб-загрузчик и медиатека для YouTube и PornHub.

## Запуск

Обычный запуск на macOS:

    ./run_mac.sh

С собственным кодом первичной настройки:

    ./run_mac.sh --setup-code "MySetupCode"

или:

    ADMIN_SETUP_CODE=MySetupCode ./run_mac.sh

Если код не передан, при первом запуске приложение само сгенерирует его и выведет в консоль.

После первичной настройки код больше не нужен: пароль администратора хранится в SQLite в виде хэша.

## Консольный лог

Приложение пишет в консоль запуск сервера, HTTP-запросы, входы/выходы, получение форматов, постановку загрузок в очередь, старт/завершение/ошибки скачивания, ручные загрузки, удаления и автоматическую очистку TTL.

## Что умеет

- локальный HTTP-сервер на 127.0.0.1:1616;
- обязательная админская авторизация;
- задаваемый setup-код;
- отдельная кнопка получения метаданных перед скачиванием;
- URL-анализ через yt-dlp;
- предпросмотр названия, превью, автора, длительности и исходного разрешения;
- выбор разрешения, MP4/WebM или MP3 128/320 кбит/с;
- фоновая очередь загрузок;
- хранение видео на сервере;
- TTL: 12 часов по умолчанию, 24 часа, 3/7/30 дней или бессрочно;
- автоматическое удаление просроченных файлов;
- просмотр, скачивание и удаление;
- автоматическое извлечение MP3 через ffmpeg;
- отправка больших видео в Telegram частями по 45 МБ;
- ручная загрузка локального видео;
- JSON-ошибки для API вместо HTML-редиректов при истёкшей сессии;
- SQLite.

## Ручная установка

    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install -U pip
    python -m pip install -r requirements.txt

С заданным setup-кодом:

    ADMIN_SETUP_CODE=MySetupCode PORT=1616 HOST=127.0.0.1 python index.py

## FFmpeg

Для источников с раздельным видеопотоком и аудиопотоком нужен ffmpeg:

    ffmpeg -version

## Cookies

Если конкретный источник требует доступ/возрастную проверку:

    export YTDLP_COOKIEFILE=/absolute/path/cookies.txt

Не коммить реальные cookies.

## Переменные окружения

PORT, HOST, WAITRESS_THREADS, SESSION_SECRET, COOKIE_SECURE, ADMIN_SETUP_CODE, YTDLP_COOKIEFILE, YTDLP_USER_AGENT, YTDLP_SOCKET_TIMEOUT, MAX_UPLOAD_BYTES, TELEGRAM_API_URL и TELEGRAM_LOCAL_API.

## Зависимости для macOS

Текущий yt-dlp требует современный Python; для этого проекта используется Python 3.11+.

    brew install python@3.13
    brew install deno
    brew install ffmpeg

`run_mac.sh` автоматически пересоздаст `.venv`, если старое окружение было создано на Python 3.9/3.10.

## YouTube

Современный YouTube требует JavaScript runtime для полноценной работы yt-dlp. В проекте используется `yt-dlp[default]`, включая EJS; на macOS рекомендуется Deno.

При ошибке `The page needs to be reloaded` приложение повторяет YouTube-запрос с `player_client=default,web_embedded`, включая случай использования `YTDLP_COOKIEFILE`.

Некоторые ролики YouTube могут дополнительно требовать актуальный PO Token. Это ограничение самого YouTube/yt-dlp.

## PornHub

Поддерживаются ссылки вида:

    https://rt.pornhub.org/view_video.php?viewkey=68420c412dc72

Перед передачей в yt-dlp ссылки `rt.pornhub.org` нормализуются к каноническому `www.pornhub.com` с сохранением пути и `viewkey`.

## Ограничение области

Приложение разрешает URL только YouTube и PornHub и не пытается обходить DRM или платный доступ. Поддержка конкретного URL зависит от актуального extractor-а yt-dlp.


## Telegram-бот

Бот настраивается в веб-интерфейсе после входа администратора.

### Telegram

1. Создай бота через @BotFather и получи Bot API token.
2. В разделе «Telegram-бот» вставь token и включи Telegram.
3. Пользователь пишет боту `/access КЛЮЧ`.
4. После выдачи доступа отправляет ссылку на YouTube или PornHub.
5. Бот последовательно предлагает качество, MP4/WebM и срок хранения.
6. Во время загрузки бот редактирует одно сообщение примерно раз в 5 секунд, показывая процент, скорость и примерный остаток времени.
7. Бот умеет скачивать MP3 в 128 или 320 кбит/с и отправлять его как аудио.
8. Для видео можно выбрать обычную отправку одним файлом или разбиение на части по 45 МБ. Части создаются локально через ffmpeg и отправляются последовательно.
9. Команда `/videos` показывает все сохранённые на сервере медиафайлы с кнопками просмотра/отправки.
10. Команда `/status` показывает состояние загрузок.

Сервер использует Telegram long polling, поэтому отдельный webhook URL не требуется.

### Публичный адрес для просмотра

Для отправки готовых видео в Telegram через URL сервер должен быть доступен Telegram из интернета. Укажи в настройках бота:

    PUBLIC_BASE_URL=https://video.example.com

или задай тот же адрес полем «Публичный адрес» в веб-интерфейсе.

Без публичного адреса файлы в пределах лимита Telegram отправляются прямо в чат; для более крупных файлов можно выбрать разбиение по 45 МБ.

### Большие файлы через Local Bot API

Обычный облачный Bot API Telegram ограничивает прямую отправку файлов 50 МБ. Telegram официально предлагает Local Bot API Server, который позволяет загружать файлы до 2000 МБ. В настройках «Telegram-бот» можно указать адрес локального Bot API и включить флажок «локальный API».

Например:

    TELEGRAM_API_URL=http://127.0.0.1:8081
    TELEGRAM_LOCAL_API=1

После переключения бота на Local Bot API следуй инструкции Telegram по переходу с облачного API, включая `logOut`, если это требуется серверу.

### Ключ доступа

В веб-интерфейсе генерируется общий ключ приглашения для пользователей Telegram-бота. Знание этого ключа даёт обычному пользователю доступ только к бот-функциям загрузки и своей библиотеке, не к админке.

Смена ключа блокирует новых пользователей со старым ключом, но уже авторизованные пользователи сохраняют доступ.

Токен бота не выводится в интерфейсе после сохранения и хранится локально в SQLite. Не публикуй его и не коммить базу данных.
