# inhHAB

Локальный веб-загрузчик и медиатека для YouTube и PornHub.

## Что сделано

- локальный HTTP-сервер на 127.0.0.1:1616;
- обязательный вход администратора;
- первичная настройка через одноразовый код в терминале;
- URL-анализ через yt-dlp;
- выбор доступного разрешения и контейнера MP4/WebM;
- очередь загрузок в фоне;
- хранение видео на сервере;
- TTL: 12 часов по умолчанию, 24 часа, 3/7/30 дней или бессрочно;
- автоматическое удаление просроченных видео примерно раз в минуту;
- главная страница показывает все видео, которые сейчас находятся на сервере;
- просмотр, скачивание и удаление;
- ручная загрузка локального видео администратором;
- SQLite без отдельного сервера.

## Запуск

    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install -U pip
    python -m pip install -r requirements.txt
    PORT=1616 HOST=127.0.0.1 python index.py

Для macOS есть run_mac.sh.

После первого запуска код первичной настройки появится в терминале. Открой /setup, введи этот код и задай пароль.

## FFmpeg

Для источников с раздельным видеопотоком и аудиопотоком нужен ffmpeg для объединения. Проверь:

    ffmpeg -version

## Cookies

Если конкретный источник требует доступ/возрастную проверку, yt-dlp можно запускать с Netscape cookies-файлом:

    export YTDLP_COOKIEFILE=/absolute/path/cookies.txt

Не коммить реальные cookies.

## Переменные окружения

PORT, HOST, WAITRESS_THREADS, SESSION_SECRET, COOKIE_SECURE, ADMIN_SETUP_CODE, YTDLP_COOKIEFILE, YTDLP_USER_AGENT и YTDLP_SOCKET_TIMEOUT.

## Ограничение области

Приложение разрешает URL только YouTube и PornHub и не пытается обходить DRM или платный доступ. Поддержка конкретного URL зависит от актуального extractor-а yt-dlp: сайты периодически меняются.

Используй загрузку только для материалов, которые тебе разрешено скачивать и хранить.
